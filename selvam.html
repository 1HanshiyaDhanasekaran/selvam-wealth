Backup & Restore
Everything stays on this device — no account, no cloud, nothing sent anywhere. Selvam automatically keeps a few recent restore points here as a safety net, and you can download a full backup file anytime to move data between your phone, Windows, and Mac.
Moving to a new device (iOS, Android, Windows, Mac)? Tap Download backup here, send that file to the new device (AirDrop, email, USB, whatever you normally use), open Selvam there, then tap Restore from backup file and pick it.
