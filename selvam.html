How entries are shown

Portfolio Region
Tag each asset with a region (Add/Edit Asset → Region) to switch your Portfolio between showing everything, just one country, or comparing both — useful when your money is split across places like India and the UK.
Exchange Rates
Enter how much 1 unit of each currency is worth in ₹ (INR) — e.g. if $1 = ₹83, enter 83 for USD. Look this up on Google ("1 USD to INR") and type it in; update it here whenever you want a fresher number.
Backup Status
Live local backup active
Waiting for first change…
Every change you make is written to this device immediately, to two separate storage slots (a primary copy and a live mirror). If one ever gets corrupted, the app automatically recovers from the other the next time it opens. Tap Backup Now anytime to force an extra restore point on the spot.
Backup & Restore
Everything is local-only — there's no cloud account and nothing leaves this device. Data saves to this device in real time as you use the app, with rotating restore points kept automatically as an extra safety net below. Download backup and Export summary report let you choose exactly where to save the file.
Moving to a new device (iOS, Android, Windows)? Tap Download backup here, send that file to the new device (AirDrop, email, cloud drive, USB — whatever you normally use), open Selvam there, then tap Restore from backup and pick the file.
Danger Zone
Permanently deletes all assets, income, expenses, goals and snapshots from this device. This cannot be undone — make sure you have a recent backup first.
Local Restore Points
Selvam automatically saves a snapshot to this device roughly every 10 minutes of use, and always right before an import or a "Clear all data." If something goes wrong, roll back to any of the last 6 points below.
